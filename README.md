> 押金该退多少 / 投诉该找谁 / 被裁公司欠你几笔 —— 输入你的数字，输出**金额区间 + 条文出处 + 可复制的文书**。
> 纯前端单页，数据不出浏览器，断网可用。作者：林小黑。

在线版：**https://samforce2003.github.io/yingzhang/**

## 为什么是「单个 HTML 文件」

要填的东西太敏感：工资、合同、聊天记录、房东姓名。这类数据一旦上传到某台服务器，就收不回来了。

所以：

- **零依赖**。没有框架、没有 CDN、没有外链字体、没有统计脚本。每个工具就是一个 HTML 文件。
- **算在本地**。全部逻辑在浏览器里跑，`grep -r "fetch(" .` 的结果是空。
- **能离线**。右键「另存为」存到本地，双击即可打开，断网照样用。
- **能被检查**。源码就是这三个文件，任何人可以读。

移动端都做过 320 / 390 / 1280 三个宽度的验收：无横向溢出、无 console 报错、存储被禁用时不崩。

## 它不做什么

这一段比上面都重要。

- **不预测结果。** 算的是「按公开条文你手上有哪些项、大概多少钱」，不是「你能拿到多少钱」。结果取决于证据、地方口径和对方抗辩。
- **不给「你应该去仲裁」这类结论。** 走不走程序，取决于你的时间、证据和风险承受度。
- **不覆盖地方细则。** 社平工资、加班费基数、仲裁实务口径各地不同；工具给全国口径，并在需要「以当地为准」的地方明确标注。
- **不构成法律意见。** 金额给区间，文书给草稿。金额重大或情形复杂，请找执业律师。

## 主要依据

- 《中华人民共和国劳动合同法》第四十七条（经济补偿 N，社平三倍封顶与 12 年上限）、第八十二条（未签书面合同二倍工资）、第八十七条（违法解除 2N）
- 《中华人民共和国消费者权益保护法实施条例》第二十条至第二十二条（押金事先约定退还方式与时限；停业或迁移须提前 30 日公告；预付式消费书面合同应载明事项）
- 《中华人民共和国民法典》租赁合同章

条文均按官方发布原文抄录，工具内标了出处。**发现引用有误请开 issue**——这类错误不会报错，只会给一个看起来很像真的结果，是最该被挑出来的那种错。

### 关于 h5/ 那两个

给写前端的人用的。底子是在 **221 个真实 AI 生成页面**上跑出来的统计：24% 用了 `100vh`（移动端地址栏一收就塌）、10% 裸调 `localStorage`（无痕模式下直接抛错）、31% 至少有一条运行时问题。命令行版（Playwright，可接 CI）见 CSDN 资源《AI生成H5批量体检方案》。
